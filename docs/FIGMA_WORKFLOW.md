# Figma ↔ 网页 UI 工作方式

当前编辑入口：[Web UI · 网页同步工作台](https://www.figma.com/design/dMTkLJIoHltbNzgH0VjoMz/?node-id=2413-65)。旧画布保留为设计参考，后续请优先修改这个工作台，避免出现两份不同版本。

- **Main · 网页主界面**：控制按钮、竖向音量、中央当前 HITS 面板、右侧累计与每次/每秒收益、商店入口、帮手图形及背景。最新画布恢复了中央 HITS 面板，商店顶部也保留余额。
- **Shop · 网页商店（同步编辑此画框）**：商店面板、固定顶部余额、关闭按钮、可裁切的拖动画布与全部技能。修改节点位置或图标时，请保留技能图层名称。
- **States · 交互状态与提示**：暂停/继续、声音/静音、五种技能节点状态、技能说明、确认弹窗、浮字/粒子及异常恢复提示。技能节点状态和主界面按钮具有可复用组件。

修改后，在对话里说“同步 Figma UI 到网页”，并给出对应画框链接或指出修改范围。Codex 会重新读取参数与素材、修改代码并检查结果。这不是持续监听或实时双向同步。

余额、等级、价格和收益文字是布局示例；网页始终由游戏逻辑计算。商店继续逐步显示技能，完整技能树需要拖动画布查看。示例状态用于编辑外观，不代表网页自动发生了相应状态变化。

网页使用 HTML/CSS/JavaScript。主要对应关系：`styles/ui.css` 控制基础外观，`styles/ui-sync.css` 保存当前 Figma 同步的布局和组件样式；`js/shop.js` 的 `treeLayout`、`treeIconOffsets`、`treeLineGeometry` 控制节点和连线；`assets/figma/shop-*.svg` 是原始技能图标，`main-*.svg` 与 `state-*.svg` 是按钮与特效的原始导出。`figma-ui-map.json` 记录当前画框与技能图层 ID，供后续同步定位。

`styles/ui-motion.css` 保存网页动效：主界面固定模块错开节奏轻晃，交互图标悬浮时放大、上浮及倾斜。420ms 内的连续有效手动点击触发 HITS 面板额外抖动，幅度随连点次数增加且有上限，停点后 320ms 回稳。系统选择减少动态效果时关闭这些位移动效。背景采用原始暗纹的单图形均匀平铺，180 秒无缝向右下循环；这些动效参数来自后续对话要求。

新增波浪视觉层由 `js/wave-rules.js`、`js/wave.js` 和 `styles/wave.css` 管理，按累计收益交替升起橙色/米色波浪，蓄满后成为带暗纹的背景。翻腾随手动点击速度变化，点击生成上浮水汽；参数与轮次门槛记录在 WAVE_EFFECTS.md。最新 Figma 余额标题/数字使用 4px/2px 外描边（CSS 中用双倍居中描边并先描边后填充），未满足前置条件的连线改为 `#327F64`、50% 透明度。

主界面按 1440×900 建立编辑画框；网页保留窄屏适配。商店最大 873×600，内部技能画布 1600×1000，中心为 (800,500)。悬浮说明、确认弹窗和反馈的中文文字在 Figma 与网页统一使用 Noto Sans SC；网页字体按游戏文字裁剪为约 130 KB 的本地 WOFF2。像素标题与数值统一使用 Jaro。增加新的中文文案时，需要更新字体子集。
