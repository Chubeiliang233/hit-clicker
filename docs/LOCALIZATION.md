# 中英文本地化

唯一文案编辑入口是 `outputs/localization-20261019/Hit Clicker 中英文文案（技能说明扩写）.xlsx`，包含已由创作者审阅的 199 项文案。保留原表的中文、英文、换行和数值占位符，不从旧代码或最早的表格覆盖回来。

## 修改与同步

编辑 B 列中文、C 列英文及 E 列备注；I 列文案编号和 G 列占位符说明保持不变。备注用于协作，不执行为代码或游戏规则。保存 Excel 后运行：

```sh
python scripts/build_locales.py
```

也可显式传入另一份经确认的最终表格路径。脚本只读取表格，检查空译文、重复编号和未知占位符，生成 `locales/zh-CN.json`、`locales/en.json` 以及直接打开本地 HTML 也可加载的 `locales/copy.js`。网页不需要网络翻译服务或构建服务器。

新增中文字符后，使用完整的 Noto Sans SC 源字体重建本地 WOFF2 子集：

```sh
python scripts/subset_font.py path/to/NotoSansSC.ttf
```

字体脚本需要 fonttools 和 brotli；完整字体仅用于构建。网页仍只加载本地子集。不要直接手改生成文件来维护另一份文案。

## 切换规则

- 首次进入按浏览器语言偏好选择：中文使用简体中文，英文使用英语，其他语言回退英语。
- 按钮显示点击后切换到的语言：中文界面显示 `E`，英文界面显示 `中`；悬浮提示与图标表达同一切换目标。图标原件来自 Figma `2536:306`、`2536:308`，主界面实例为 `2537:312`。
- 主动选择单独保存在 `hit-clicker-language`；刷新和重置进度均保留。存储不可用时仍能在本次会话切换。
- 切换不授予 hit、不消费余额、不重置技能、波浪或自动点击进度。
- 新收入记录保存事件编号和参数，显示时按当前语言翻译。旧记录的常见中文/英文格式会按显示时解析；无法可靠识别的旧说明保留原文。旧存档无需升级版本。

## 排版

`styles/localization.css` 管理字体和双语排版：英文游戏标题 Jaro 400，中文标题 Noto Sans SC 700/800，正文 15px/500、行高 1.55，费用与条件 14px/600，重要数值 700。余额仍用 Jaro 400/64px；节点数字 20px。手机正文 14px、技能标题中文 16px/英文 20px、余额 32px。HITS 标题按创作者选择在两种语言中均保留。

悬浮说明正文宽度中文 340px、英文 380px，并受屏幕宽高限制；标题居中，正文与前置条件分行，保留文案表中的换行。超长内容在窗口内滚动，不靠缩小字号塞入固定高度。

## 验证

`tests/localization-browser.test.cjs` 覆盖首次语言、手动选择记忆、重置保留、最终表文案、全部技能的双语参数、历史记录、图标尺寸、窄屏、存储拒绝和回退语言。已有游戏、商店交互、动效与波浪测试继续作为回归检查。
