# 运势表盘

解锁「运势」技能后显示；旧存档已解锁时直接恢复显示，重置后隐藏。桌面位于 HITS 下方，手机位于音量下方、商店左侧；手机解锁后为下方小帮手额外留出空间。

- 半圆指针：运势 0–100 对应 −90° 到 +90°，数值更新过渡 300ms。
- 三颗圆点：表示当前三次手动点击周期中的进度，更新运势时清空。
- 升降反馈：箭头和变化量显示 900ms。上涨弹起 4px，下降下沉 2px，各 300ms；上涨星点 650ms。
- 已购买欧皇且运势 100：皇冠出现，以 2 秒周期柔和发光。离开 100 后收起。
- 已购买氪能救非、运势低于 50 且低运势点击达到 100：盾牌出现；下跌 2 时闪亮 350ms。
- 悬浮、键盘聚焦或点击表盘显示详细信息；Escape、失焦、点击外部收起。手机可点击查看。
- 暂停时停止表盘晃动和皇冠呼吸；系统减少动态效果设置下取消这些循环动画和反馈位移动画。

`js/fortune.js` 只负责显示，`js/game.js` 的 `updateDisplay()` 传入实时状态。数值规则、收益计算、购买条件和存档格式保持原样。文案复用最终文案表现有的运势、幸运及关联技能状态词条，中英文切换即时生效。

浏览器验证：`node tests/fortune-browser.test.cjs`（Playwright 配置同 tests/README.md）。
